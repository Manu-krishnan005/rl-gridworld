Q-Learning Algorithm
An off-policy temporal-difference algorithm. Learns the optimal Q*(s,a) function regardless of which policy the agent follows. Converges to optimal policy given sufficient exploration.
Q(s,a) ← Q(s,a) + α[r + γ max Q(s',a') − Q(s,a)] α = learning rate, γ = discount factor
🎲
ε-Greedy Exploration
Balances exploration (random actions) and exploitation (best known action). ε decays each episode so the agent gradually shifts from exploring to exploiting.
π(a|s) = random action if rand < ε = argmax Q(s,a) otherwise ε ← ε × decay (each episode)
🏆
Reward Structure & SARSA
The reward function shapes agent behaviour. SARSA is on-policy: it uses the actual next action taken, leading to safer but sometimes slower convergence than Q-Learning.
Goal: +100 | Trap: −10 Wall hit: −5 | Each step: −0.5 SARSA: Q(s,a) ← Q(s,a) + α[r + γ Q(s',a') − Q(s,a)]
